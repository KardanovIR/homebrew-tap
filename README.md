# KardanovIR Homebrew tap

```bash
brew install kardanovir/tap/agstatus
agstatus init
```

[AgStatus](https://agstatus.online) — live status board + push alerts for
your coding agents (Claude Code, OpenAI Codex).
Source: [KardanovIR/claude-status-dashboard](https://github.com/KardanovIR/claude-status-dashboard).

The formula is updated automatically by the main repo's release workflow on
every `v*` tag.
